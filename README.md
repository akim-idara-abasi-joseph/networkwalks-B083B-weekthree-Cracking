# Week 3 – Password Cracking Labs

## Project Overview

This repository contains my Week 3 practical exercises completed during my Cybersecurity & Ethical Hacking Internship at Networkwalks.

The objective of these labs was to understand how password cracking works in a controlled and authorized environment using different password recovery tools. The activities demonstrated how weak passwords can be recovered from password-protected files and reinforced the importance of using strong passwords to protect sensitive information

---

# Project Module 1
## Password Cracking with John the Ripper (JTR)

### Objective

The objective of this lab was to recover the password of an encrypted PDF file using John the Ripper (JTR) and Johnny GUI. This exercise demonstrated how password recovery tools can be used by security professionals to evaluate password strength during authorized security assessments. :contentReference[oaicite:2]{index=2}

### Activities Completed

- Downloaded and installed John the Ripper.
- Installed the Johnny graphical interface.
- Configured Johnny to use the John executable.
- Downloaded the encrypted PDF file.
- Extracted the PDF password hash.
- Saved the extracted hash into a text file.
- Imported the hash into Johnny.
- Started the password cracking process.
- Successfully recovered the password.
- Opened the encrypted PDF using the recovered password.

### Result

The password was successfully recovered, allowing the encrypted PDF document to be opened successfully. All steps were completed without any issues.

# Project Module 2
## Password Cracking using Networkwalks Tools

### Objective

The purpose of this lab was to recover the password of an encrypted PDF using the Networkwalks Hash Calculator and Password Cracker. The exercise demonstrated a browser-based password recovery workflow without requiring software installation.

### Activities Completed

- Downloaded the encrypted PDF.
- Opened the Networkwalks Hash Calculator.
- Uploaded the encrypted PDF.
- Generated the PDF hash.
- Copied the complete hash value.
- Opened the Networkwalks Password Cracker.
- Submitted the extracted hash.
- Started the password recovery process.
- Successfully recovered the password.
- Used the recovered password to unlock the PDF.

### Result

The password was successfully recovered using the Networkwalks online tools.
